# 自己メンテナンス 要件定義書 v1.0

## 概要

- App Store名: 自己メンテナンス
- ホーム画面表示名: 自己メンテ
- サブタイトル: 美容と健康の自己投資手帳
- コンセプト: 自己メンテナンスの「そろそろ」を忘れない

美容院、歯科、眉毛サロン、まつパ、脱毛、整体、健康診断など、定期的に行う美容・健康・身だしなみ・セルフケアの履歴と次回目安を管理する。

## MVPスコープ

- メンテナンス項目登録
- プリセット13種
- 自由項目追加
- 実施履歴登録
- 次回目安日の自動計算
- 次回目安日の手動調整
- ホームのステータス表示
- カレンダー表示
- 支出集計
- 人型の部位別支出マップ
- ローカル通知
- 非表示項目管理
- 完全削除
- 全データ削除
- ローカル保存
- テーマ切り替え

## 非スコープ

- 店舗検索

- アカウント作成

## ステータス

| 状態 | 表示文言 |
|---|---|
| 未記録 | まずは前回日を記録 |
| まだ余裕 | まだ余裕 |
| そろそろ | そろそろ予約確認 |
| 目安付近 | 目安日に近いです |
| 期限超過 | ○日過ぎています |

- 目安付近: 次回目安日の-3日から+2日
- 期限超過: 次回目安日の3日後以降
- そろそろ開始: 周期日数の20%、最小7日、最大30日

## App Storeスクリーンショット文言

1. 自己メンテナンスの「そろそろ」を忘れない
2. 前回の日付と次回の目安が、すぐわかる
3. 美容院・脱毛・歯科などをまとめて管理
4. 美容と健康の自己投資を見える化
5. 次のタイミングを通知でお知らせ
